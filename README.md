## ✨ Novedades de la Versión 0.2.0
- **Modo Kiosco / Pantalla Completa:** La aplicación inicia automáticamente en pantalla completa optimizada para puntos de venta.
- **Planes Escalonados:** Introducción de Plan Bodega ($15), Plan Negocio Pro ($22) y Plan Supermercado Max ($35).
- **Licencia Comercial Vitalicia:** Modalidad de compra definitiva sin mensualidades.
- **Protocolo de Resguardo de Datos:** Suspensión preventiva con copia de seguridad encriptada sin pérdida de registros.
- **Sincronización en Vivo:** Tasa oficial del BCV (USD / EUR) con soporte 100% offline.

## 🔄 Actualizaciones Automáticas (OTA)
Este repositorio aloja el manifiesto `version.json` consultado de forma segura por la aplicación de escritorio para verificar y descargar parches sin necesidad de tokens ni autenticación.
